# Tâche planifiée à créer : compléter les idées de cadeaux ajoutées par lien

Dans l'app Claude, section « Scheduled » : nouvelle tâche, identifiant `cadeaux-completer-idees`, horaire `30 8,19 * * *` (8 h 30 et 19 h 30 tous les jours), mode Auto. Coller la consigne ci-dessous telle quelle.

---

Tu complètes les idées de cadeaux que les parents ont ajoutées par un simple lien sur le site familial « Les listes de Noël » (https://charlp0.github.io/cadeaux2026/). Travaille en français. Projet : /Users/charlesperrot/Documents/Claude/CODE/cadeaux2026 (dépôt GitHub charlp0/cadeaux2026, branche main, GitHub Pages). Lis l'en-tête de scripts/idees.js avant de commencer.

1. Dans le projet, exécute `node scripts/idees.js list`. S'il rend un tableau vide, termine en une ligne (« aucune idée à compléter ») sans rien modifier.
2. Pour chaque idée (champs liste, id, url, et éventuellement nom/prix/boutique saisis par les parents) :
   a. Lis la page du lien : d'abord WebFetch ; si elle est bloquée (403, captcha, page vide), ouvre-la dans le navigateur intégré (mcp__Claude_Browser__*) et lis-la avec get_page_text / read_page, refuse les cookies si on te le demande. Relève : nom du produit (court, sans slogan), description utile en une ligne (taille, contenu, référence), marque, âge minimum s'il est indiqué, prix affiché en euros, nom de la boutique (ex. Fnac, Decathlon, Cultura), et l'adresse de la photo principale (balise og:image ou première image produit).
   b. Télécharge la photo avec curl (User-Agent de navigateur) dans img/custom/<id>.jpg, puis `sips -Z 600` pour la réduire. Si le téléchargement échoue, mets img à null (la page affichera une image de secours).
   c. Prix Amazon : ouvre https://www.amazon.fr/ dans le navigateur intégré (bouton « Refuser » pour les cookies) et cherche le produit avec javascript_tool : `fetch('/s?k='+encodeURIComponent(nom))` puis DOMParser sur `div[data-component-type="s-search-result"]` (attribut data-asin, titre h2, prix `.a-price .a-offscreen`). Garde le premier résultat qui est clairement le même produit ; sinon amazon = {prix:null,url:null,note:"Pas trouvé sur Amazon.fr"}. Lien = https://www.amazon.fr/dp/<ASIN>.
   d. Moins cher ailleurs : une recherche WebSearch (mode standard) « <nom du produit> prix » pour trouver un vendeur français établi (Fnac, Cdiscount, Darty, Boulanger, Decathlon, Cultura, E.Leclerc, Auchan, Carrefour, site de la marque…) moins cher que la boutique du lien. Si rien de moins cher : ailleurs = {vendeur:null,prix:null,url:null,verifie:false,note:"Rien de moins cher trouvé"}. verifie:true seulement si tu as lu le prix sur la page du vendeur.
   e. Écris une fiche JSON dans ton scratchpad : {"nom","sub","marque","age","boutique","prix","url","img":"img/custom/<id>.jpg" ou null,"amazon":{"prix","url","note"},"ailleurs":{"vendeur","prix","url","verifie","note"}} (prix en nombres, hors frais de port). Garde le nom, le prix ou la boutique saisis par les parents s'ils en ont mis.
   f. Exécute `node scripts/idees.js done <liste> <id> <chemin de la fiche>` : il intègre la fiche dans data.js et supprime l'idée en ligne. Si le lien est mort ou n'est pas un produit, n'intègre rien et laisse l'idée en ligne, signale-le dans le résumé (`drop` seulement si le lien est manifestement une erreur de saisie, comme une page d'accueil).
3. Quand toutes les idées sont traitées : `git status` (seuls data.js et img/custom/ doivent avoir changé), puis commit (message « Idées complétées du AAAA-MM-JJ : <noms> », terminé par la ligne « Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com> ») et `git push origin main`.
4. Termine par un résumé en 5 lignes maximum : idées complétées (liste, nom, prix, moins cher trouvé), idées non complétées et pourquoi. Ne demande rien à l'utilisateur.
